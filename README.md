# School scheduler

A Python tool powered by CP-SAT (OR-Tools) to build school timetables (teachers, classes and rooms). The task is modeled by a combinatorial optimization problem.

This project is currently a work in progress at the starting stage.

## Personal note

This project was ignited by my will to create a project of applied mathematics. Amongst many ideas, I wanted to make something that feels more real rather that just a project for fun.
When I was a teacher I noticed that building the timetables was always a complex task due to the many constraints and personal wishes to consider. As a mathematician, I thought that I should give this problem a try.

Goals:
- Apply my maths skills to modelize a concrete real-life situation.
- Improve my Python skills
- Learn how to manipulate data through a database
