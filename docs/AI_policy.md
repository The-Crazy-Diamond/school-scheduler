# AI Usage Policy

AI is used in this project to assist with technical setup, provide guidance
on project structure, and review or improve code.

However, AI should not replace the learning process. In particular, the goal
is not to use AI to complete the project as quickly as possible, since there
is no time constraint on its development.

My goal is to find a balance between doing things myself to develop a deeper
understanding and learning how to use AI effectively as part of a modern
development workflow.
